Настройка Git:
    - Проверка версии:
        - git version
    - Настройка пользователя:
        - git config --global user.name "Имя"
        - git config --global user.email "Почта"
    - Выбор ветки по умолчанию:
        - git config --global init.defaultBranch main

Инициализация нового репозитория:
    - git init
    - git init -b main

Основные операции:
    - Проверка состояния:
        - git status
    - Добавление файлов в индекс:
        - git add <имя_файла>
        - git add .
    - Создание коммита:
        - git commit -m "Описание изменений"
    - Просмотр истории:
        - git log
        - git log --oneline
        - git log --graph
    - Просмотр изменений:
        - git show <хеш_коммита>

Работа с ветками:
    - Создание и переключение:
        - git switch -c <имя_ветки> - создать и перейти 
        - git checkout -b <имя_ветки> - альтернативный способ 
    - Переключение между ветками:
        - git switch <имя_ветки> - перейти на существующую ветку
        - git switch - вернуться к предыдущей ветке
    - Управление ветками:
        - git branch - список локальных веток
        - git branch -a - все ветки (локальные и удалённые)
        - git branch -d <имя> - удалить ветку
        - git branch -D <имя> - принудительное удаление
        - git branch -m <новое_имя> - переименовать текущую ветку

Работа с удаленным репозиторием: 
    - Подключение удалённого репозитория:
        - git remote add origin <URL>
    - Отправка изменений:
        - git push -u origin main - первый push с установкой отслеживания
        - git push - последующие push 
        - git push origin <ветка> - отправить конкретную ветку
    - Получение изменений:
        - git pull - получить изменения и слить
        - git fetch - только получить изменения без слияния
        - git fetch --prune - удалить ссылки на удалённые ветки
